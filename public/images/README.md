# Images Directory

Place the following images from the original website (http://ralogistics.co.in/) in this directory:

1. **hero-bg.jpg** - Hero section background image
2. **ground-shipping.jpg** - Ground shipping service image
3. **air-freight.jpg** - Air freight service image
4. **roadways.jpg** - Roadways service image
5. **express.jpg** - Express service image
6. **airfreight.jpg** - Airfreight service image
7. **warehouse.jpg** - Warehouse service image

## How to Get Images

You can download images from the original website using browser developer tools:
1. Open http://ralogistics.co.in/ in your browser
2. Right-click on images and select "Save Image As..."
3. Save them to this directory with the names listed above

Alternatively, you can use the browser's Network tab to find image URLs and download them.

## Image Specifications

- Hero background: Recommended size 1920x800px
- Service images: Recommended size 600x400px
- All images should be optimized for web (JPG or PNG format)
